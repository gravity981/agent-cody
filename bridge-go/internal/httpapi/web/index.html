WSL relays

Configure Claude Code hooks to use the relay

  1. In Cody's WSL relay configuration, include the distribution that runs Docker Engine. If you change the list, save the settings and select Restart now. Wait for that distribution's Docker Engine gateway address to appear above.
  2. In the Docker Engine devcontainer where Claude Code runs, go to the Cody repository root and run the installer command shown for that distribution. Run it in the environment that owns Claude Code's settings file; a shared Claude configuration volume only needs one install. Run it again if the relay port changes, then restart Claude Code to reload its hooks.

The hooks try 127.0.0.1:8765, then host.docker.internal:8765, then 172.17.0.1:<relay-port>. The installer's --port sets only the last target, using the port shown above for the same distribution.

For Claude Code running directly on Windows or in WSL, omit --port; those hooks use 127.0.0.1:8765. Docker Desktop devcontainers also use the default port and do not use this WSL relay setting.
